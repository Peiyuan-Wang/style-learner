# 学习与合并

## 提炼维度

依据真实材料选取有辨识力的维度，不要求填满所有项目：

- 语气与叙述视角：直接程度、读者距离、第一人称、确定性与保留措辞。
- 句法与节奏：长短句交替、从句密度、主动/被动、停顿、标点。
- 措辞：口语/书面语、术语密度、抽象程度、偏好和回避表达。
- 段落与篇章：开头方式、中心句位置、段落推进、收束习惯。
- 论证：主张与证据的顺序、让步、反例、因果限定、引用整合。
- 修辞与格式：例子、比喻、问句、标题、列表；区分作者习惯与投稿模板。
- 语言、受众和场景边界：中文学术特征不直接推广为英文邮件规范。

计数可用来核查印象，但没有实际测量不要报告精确句长、比例或统计显著性。单篇论文的 IMRaD 结构可能来自体裁，不能直接当作作者独有风格。

## 档案建议格式

```markdown
# 风格名称
适用范围：语言、体裁、受众；尚不明确的部分。
样本概况：来源性质、覆盖范围、已分析的独立材料数量（仅在能核实时填写）。

## 已确认偏好
- [R1] 可执行的写作规则。来源：用户明确纠正。范围：……

## 有证据支持的习惯
- [R2] 特征 → 写作时如何落实。置信度：中。证据：材料 A 的引言与讨论；材料 B。例外：……

## 待验证
- [R3] 仅出现一次的倾向。保留为假设，不强制执行。

## 避免与边界
- 不喜欢的表达；仅在哪些场景适用。
```

## 增量更新规则

用户明确的持久偏好优先于统计推断。同一材料重复导入不能增加置信度；来自不同段落不一定是独立作品。两份以上独立材料中的一致习惯可提高置信度，但数量门槛不取代判断。不要把一次偏差改写成“用户一贯如此”。

保留仍有效的旧规则。新旧材料冲突时优先细分适用范围；不明时同时保留证据并降低确定性。只有明确纠正或足够新证据才替换稳定规则。来源是第三方作品时始终保留参考风格标签。

持久记录只含分析摘要。示例优先用自造的短句，明确标记为示意，不冒充用户原文。证据定位可用匿名材料编号与章节，避免把论文作者、文件全路径或聊天中的私人事实写入库。

## 去重

有可靠消息 ID 时用“会话 ID + 消息 ID + 分析版本”生成 source_key；作品用提取文本的 SHA-256。脚本也支持对本地文本文件运行 `fingerprint --file ...`。重复导入同一作品不累计证据；用户要求重新分析时使用“原 source_key + 明确的重新分析版本”，并说明是重新分析，非新增独立样本。不要用每次不同的时间戳制造独立证据。

## 学习结果

作品导入后简要说明目标 style、实际读取范围、主要新特征、仍不确定之处以及是否保存成功。如果用户仅要求学习，不附送未经要求的仿写全文。只有用户要求仿写时才生成新作品。
